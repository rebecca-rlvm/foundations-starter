# Homework: Strings

## Objective
This homework will test how you manipulate and format strings to produce a specific output from user input. To do this, you will create a MadLib where the user can input words and see them printed within a passage. 

For this homework, you will complete three tasks:

1. Make the `get_input` function collect multiple user inputs and store them.
2. Make the  `print_passage` function correctly print out the MadLib with user inputs imbedded.
3. Make the `ending_prompt` function ask the user if they want to repeat, and then either repeat or print a formatted goodbye message.
